# 취조실 (Interrogation)

시대 불명의 점령 도시, 창 없는 취조실. LLM 기반 1인 NPC 심문극.

당신은 **괴도**다. 비리 정치인과 사기꾼의 집만 골라 털었고, 나온 것은 전부 굶은 자들에게 갔다.
세 해 동안 한 번도 틀리지 않았다. 그러다 장갑 한 짝을 두고 나왔다.

형사는 두 가지를 캔다 — **당신이 훔쳤는가**, 그리고 **훔친 것이 어디로 갔는가.**
후자가 조직으로 이어지면 절도가 아니라 반역이 된다.
**두 혐의를 동시에 낮게 유지한 채 취조실을 나가는 것이 승리.**

---

## 처음 받았을 때 (3단계)

### 1. 유니티 버전 맞추기 — 제일 중요

**반드시 `Unity 6.3 LTS (6000.3.21f1)`로 연다.** 다른 버전으로 열면 Unity가 "업그레이드하시겠습니까"를 묻는데,
**여기서 확인을 누르면 프로젝트 파일이 바뀌어서 팀 전원이 고생한다. 취소하고 맞는 버전을 설치할 것.**

Unity Hub → Installs → Install Editor → `6000.3.21f1`
모듈은 **Windows Build Support (IL2CPP)** 만 체크하면 된다. (WebGL·Mac은 안 쓴다)

> 정확한 버전은 항상 `ProjectSettings/ProjectVersion.txt`가 기준이다. 이 파일을 직접 고치지 말 것.

### 2. API 키 파일 만들기

키는 보안상 깃에 올라가지 않는다. **각자 자기 키로 직접 만들어야 한다.**

프로젝트 루트(`Assets` 폴더와 같은 위치)에 **`apikey.txt`** 파일을 만들고 한 줄 적는다:

```
openai=sk-여기에_자기_키
```

- 키 발급: https://platform.openai.com → API keys
- ChatGPT Plus 구독과 API 키는 **별개다.** API 크레딧이 따로 충전돼 있어야 한다.
- 이 파일은 `.gitignore`에 있어서 커밋되지 않는다. **절대 강제로 올리지 말 것.**

### 3. 씬 생성하고 실행

Unity 상단 메뉴 → **`Tools > Interrogation > Setup Scene`** → 완료 팝업 뜨면 **Play**.

씬·머티리얼·한글 폰트는 전부 이 메뉴가 코드로 생성한다. 클론 직후 한 번은 반드시 돌려야 한다.

## 조작

| | |
|---|---|
| 진술하기 | 하단 입력창에 타이핑 후 Enter 또는 "답한다" 버튼 |
| 둘러보기 | **마우스 오른쪽 버튼**을 누른 채 드래그 (왼쪽 버튼은 UI용) |

형사는 머리 옆 말풍선으로 말한다. 좌하단에 대화 기록, 우상단에 게이지 두 개.

한 판은 **6턴**. 6턴이 끝났을 때 의심·불온이 **둘 다 50 미만이면 석방(승리)**,
아니면 다시 불려와 다음 판이 시작된다. 어느 쪽이든 **형사는 지난 판의 진술을 기억한다.**

---

## 안 될 때

| 증상 | 원인과 해결 |
|---|---|
| 한글이 전부 □로 보임 | `Setup Scene`을 안 돌렸다. 메뉴에서 실행할 것. |
| 화면이 텅 비어 있음 | 같은 이유. `Setup Scene` 실행. |
| 형사가 "무슨 소린지 모르겠군"만 반복 | `apikey.txt`가 없거나 키가 잘못됐다. 2번 단계 확인. |
| 형사 말이 내 대답과 무관함 | 위와 같음. 키가 없으면 사전 작성 대사만 나온다. |
| Unity가 업그레이드를 물어봄 | **취소.** 버전이 틀렸다. 1번 단계 확인. |

### 로그로 진단하기

플레이할 때마다 `PlayLogs/session_날짜.log`에 전부 기록된다 — 질문, 내 입력, 판정된 태틱,
게이지 증감, LLM 실패 원인까지. **뭔가 이상하면 추측하지 말고 이 파일부터 열 것.**

각 턴 끝에 `{LLM대사}`면 형사가 실제로 반응해 생성한 대사, `{풀대사}`면 폴백이다.

## 구조 한눈에

```
Assets/Scripts/
  InterrogationState.cs      상태·열거형·임계값·승패 판정
  Judgment.cs                모순 검출 + 게이지 계산
  InterrogationController.cs 턴 루프 (판정 → 대사 생성)
  LLMClient.cs               OpenAI/Anthropic 호출
  DialoguePool.cs            사전 작성 대사 로더
  InterrogationUI.cs         입력·로그·게이지
  SpeechBubble.cs            말풍선
  SeatedLook.cs              앉은 1인칭 시점
Assets/Editor/
  InterrogationSceneSetup.cs 씬 전체 자동 생성기
Assets/Resources/
  dialogue_pool.json         폴백 대사 + 형사 대사 풀
Assets/Docs/
  D1_스키마_확정.md           기획 확정서 (동결 — 읽고 시작할 것)
```

**설계 원칙 하나만 기억하면 된다: 판정은 전부 코드가 한다. LLM은 자연어를 데이터로 바꾸고,
코드가 정한 결과를 형사의 말투로 옮길 뿐이다.** 자세한 규칙은 `CLAUDE.md` 참조.

---

## 협업 규칙

- `main` 직접 푸시 금지. 짧은 브랜치로 작업 후 머지.
- 파일 담당이 나뉘어 있다 (`CLAUDE.md` 협업 섹션 참조). 남의 영역은 먼저 말하고 건드릴 것.
- **씬 충돌은 병합하지 않는다.** `Interrogation.unity`, `Materials/`, 폰트 에셋은 전부 코드 생성물이라
  한쪽을 고른 뒤 `Setup Scene`을 다시 돌리는 게 정답이다.
- 머지 전에 반드시 Play로 한 판 돌려볼 것.
