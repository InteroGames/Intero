# 취조실 (Interrogation)

> **창의적인 대답으로 미꾸라지처럼 빠져나가는 게임.**

냉전 시대. 국경이 그어진 지 삼 년, 말 한마디로 사람이 사라지는 도시.

당신은 **의적**이다. 줄을 잘 선 자들의 금고만 골라 열었고, 나온 것은 전부 굶은 자들에게 갔다.
세 해 동안 한 번도 틀리지 않았다. 그러다 **사소한 실수** 하나로 용의선상에 올랐다.

형사는 두 가지를 캔다 — **당신이 훔쳤는가**, 그리고 **훔친 것이 어디로 갔는가.**
후자가 조직으로 이어지면 절도가 아니라 이적 행위가 된다.

---

## 게임 개요

| | |
|---|---|
| 장르 | 추리 / 스릴러 |
| 플랫폼 | PC (Windows) |
| 모드 | 싱글플레이 |
| 예상 플레이타임 | 10시간 |
| 참고작 | Overboard! · Expelled! · GNOSIA · The Infectious Madness of Doctor Dekker |

**차별점:** LLM이 플레이어의 자유로운 발화를 이해하고 기억한다.
선택지가 없다. 무엇을 말할지는 당신이 지어낸다.

---

## 코어 루프

```
형사가 묻는다 → 진술한다 → 시간·장소·인물·행동을 추출한다
     ↑                                      ↓
형사가 반응한다 ← 의심도·불온도가 변한다 ← 이전 진술과 대조한다
```

**설계 원칙: 판정은 전부 코드가 한다.**
LLM은 자연어를 데이터로 바꾸고, 코드가 정한 결과를 형사의 말투로 옮길 뿐이다.
같은 상황에서 매번 다르게 판정되면 플레이어가 규칙을 학습할 수 없기 때문이다.

---

## 어떻게 하는 게임인가

### 1. 조사 턴 — 거짓말을 미리 설계한다

서기가 조서 카드를 두 장씩 밀어준다. 빈칸에 답을 적으면 그것이 **앞으로 6번의 신문 동안 나를 묶는 진술**이 된다.

```
┌─────────────────┐  ┌─────────────────┐
│   당시 소재      │  │    동행자        │
│ ─────────────── │  │ ─────────────── │
│ 목요일 밤 열한   │  │ 함께 있던 사람이 │
│ 시경, 어디 계셨  │  │ 있습니까.        │
│ 습니까.          │  │                 │
│ [            ]  │  │ [            ]  │
└─────────────────┘  └─────────────────┘
```

카드는 매 판 **섞여서** 나온다. 같은 사건이라도 캐묻는 곳이 달라진다.

### 2. 취조 턴 — 그 거짓말을 지켜낸다

형사가 조서를 손에 들고 파고든다. 6번의 신문 동안 진술을 지켜야 한다.

### 3. 점수

| 행동 | 결과 |
|---|---|
| 거짓을 끝까지 지켜냄 | **의심도 하락** — 유일한 득점 수단 |
| 형사가 이미 아는 것에 거짓말 | **발각.** 그 항목은 다음 판부터 확정 사실이 된다 |
| 말을 바꿈 / 지난 진술과 어긋남 | 모순으로 잡힘 |
| 묵비권·회피 | 불응으로 잡혀 의심도 상승 |
| 사실대로만 진술 | 그건 자백이다 |

**막연하게 답하면 안전하지만 얻는 것도 없다.** 구체적일수록 크게 얻고 크게 잃는다.

---

## 취조관은 판마다 바뀐다

조서가 두꺼워지는 것과 함께 **상대가 강해진다.**

| 판 | 상대 | 특징 | 체포 근거 |
|---|---|---|---|
| 1차 | **초보 형사** | 매뉴얼대로 묻는다. 지난 조서는 뒤지지 않는다 | 전부 안다 |
| 2차 | **베테랑 형사** | 조서를 대조하고, 꺼낸 이름을 미끼로 쓴다 | 어렴풋이 안다 |
| 3차 | **프로파일러** | 사건이 아니라 사람을 본다. 말버릇까지 읽는다 | **모른다** |

3차에서는 **왜 앉아 있는지조차 모른 채** 거짓말을 설계해야 한다.

## 처음 받았을 때 (3단계)

### 1. 유니티 버전 맞추기 — 제일 중요

**반드시 `Unity 6.3 LTS (6000.3.21f1)`로 연다.** 다른 버전으로 열면 Unity가 "업그레이드하시겠습니까"를 묻는데,
**여기서 확인을 누르면 프로젝트 파일이 바뀌어서 팀 전원이 고생한다. 취소하고 맞는 버전을 설치할 것.**

Unity Hub → Installs → Install Editor → `6000.3.21f1`
모듈은 **Windows Build Support (IL2CPP)** 만 체크하면 된다.

> 정확한 버전은 항상 `ProjectSettings/ProjectVersion.txt`가 기준이다. 이 파일을 직접 고치지 말 것.

### 2. API 키 파일 만들기

키는 보안상 깃에 올라가지 않는다. **각자 자기 키로 직접 만들어야 한다.**

프로젝트 루트(`Assets` 폴더와 같은 위치)에 **`apikey.txt`** 를 만들고 한 줄 적는다:

```
openai=sk-여기에_자기_키
```

- 키 발급: https://platform.openai.com → API keys
- ChatGPT Plus 구독과 API 키는 **별개다.** API 크레딧이 따로 충전돼 있어야 한다.
- 이 파일은 `.gitignore`에 있다. **절대 강제로 올리지 말 것.**

### 3. 씬 생성하고 실행

Unity 상단 메뉴 → **`Tools > Interrogation > Setup Scene`** → 완료 팝업 뜨면 **Play**.

씬·머티리얼·한글 폰트는 전부 이 메뉴가 코드로 생성한다. 클론 직후 한 번은 반드시 돌려야 한다.

---

## 안 될 때

| 증상 | 원인과 해결 |
|---|---|
| 한글이 전부 □로 보임 | `Setup Scene`을 안 돌렸다 |
| 화면이 텅 비어 있음 | 같은 이유 |
| 형사가 "무슨 소린지 모르겠군"만 반복 | `apikey.txt`가 없거나 키가 잘못됐다 |
| 형사 말이 내 대답과 무관함 | 위와 같음. 키가 없으면 사전 작성 대사만 나온다 |
| Unity가 업그레이드를 물어봄 | **취소.** 버전이 틀렸다 |

### 로그로 진단하기

플레이할 때마다 `PlayLogs/session_날짜.log`에 전부 기록된다 — 질문, 입력, 판정된 태틱,
게이지 증감, 뽑힌 체포 근거, LLM 실패 원인까지. **뭔가 이상하면 추측하지 말고 이 파일부터 열 것.**

각 턴 끝에 `{LLM대사}`면 형사가 실제로 반응해 생성한 대사, `{풀대사}`면 폴백이다.

## 협업 규칙

- `main` 직접 푸시 금지. 짧은 브랜치로 작업 후 머지
- 파일 담당이 나뉘어 있다 (`Assets/Docs/작업분담.md`). 남의 영역은 먼저 말하고 건드릴 것
- **씬 충돌은 병합하지 않는다.** `Interrogation.unity`, `Materials/`, 폰트 에셋은 코드 생성물이라
  한쪽을 고른 뒤 `Setup Scene`을 다시 돌리는 게 정답이다
- 머지 전에 반드시 Play로 한 판 돌려볼 것
