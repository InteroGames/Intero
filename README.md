# 취조실 (Interrogation)

> **창의적인 대답으로 미꾸라지처럼 빠져나가는 게임.**

냉전 시대. 국경이 그어진 지 삼 년, 말 한마디로 사람이 사라지는 도시.

당신은 **의적**이다. 줄을 잘 선 자들의 금고만 골라 열었고, 나온 것은 전부 굶은 자들에게 갔다.
세 해 동안 한 번도 틀리지 않았다. 그러다 **사소한 실수** 하나로 용의선상에 올랐다.

형사는 두 가지를 캔다 — **당신이 훔쳤는가**, 그리고 **훔친 것이 어디로 갔는가.**
후자가 조직으로 이어지면 절도가 아니라 이적 행위가 된다.

---

## 현재 상태 — 중단 (2026-08-10)

**8/10 사전 과제 마감 시점에서 작업을 멈췄다. 재개 예정은 2026년 9~10월.**

돌아가는 것과 안 돌아가는 것을 여기 적어둔다. 몇 달 뒤의 나는 이걸 다 잊었을 것이다.

| | 상태 |
|---|---|
| 2페이즈 세로 슬라이스 (잠입 → 취조) | **동작한다.** 현재의 메인 경로 |
| 단일 취조실 (레거시) | **동작한다.** 손대지 않았고 그대로 컴파일된다. 되돌아갈 자리 |
| 밸런싱 | **전부 미검증.** 수치는 전부 첫 추정값이다 |
| 3D·연출 | 프리미티브뿐. 전부 코드 생성물 |

재개할 때 무엇부터 볼지는 [맨 아래 "다시 시작할 때"](#다시-시작할-때)에 적어뒀다.

## 설계 원칙 (이걸 어기면 게임이 망가진다)

**판정은 전부 코드가 한다.** LLM이 하는 일은 두 가지뿐이다 — 자연어를 데이터로 바꾸는 것,
그리고 코드가 정한 결과를 형사의 말투로 옮기는 것. 같은 상황에서 매번 다르게 판정되면
플레이어가 규칙을 학습할 수 없고 밸런싱이 불가능해지기 때문이다.

**세계의 진실과 형사의 지식은 분리한다.** 잠입 결과(`HeistResult`)는 형사의 프롬프트
(`KnowledgeBrief()` / `HypothesisBrief()`) 어디에도 들어가지 않는다. 여기에 진실을 끌어오는 순간
형사가 전지전능해지고 게임이 붕괴한다.

**형사는 거짓말 여부를 판정하지 않는다.** "지금 형사가 쥔 증거로 반박 가능한가"만 본다.

**화면에 오류 메시지를 띄우지 않는다.** 파싱 실패, API 장애, 인젝션 시도, 욕설 — 전부 형사의
대사로 흡수된다. "입력을 이해할 수 없습니다"가 화면에 나가는 순간 몰입이 깨진다.

## 구조 — 2페이즈

```
Phase 1  잠입          Phase 2  취조
목표물 3개 → 경보  ──▶  4라운드 × 4턴
60초 탈출              증거 카드 3장
   │                        ▲
   └── 남긴 흔적이 ─────────┘
       증거 슬롯 8개의 상태를 바꾼다
```

Phase 1에서 무엇을 남겼는지가 Phase 2에서 형사가 무엇을 들이밀 수 있는지를 결정한다.
**통로는 `PhaseBridge` 하나뿐이다.**

### Phase 1 — 잠입

증거는 런타임에 생성하지 않는다. **슬롯 8개가 고정이고, 잠입 결과가 상태만 바꾼다.**
변환 규칙은 전부 `HeistOutcome.Seal()` 한 곳에 있다.

| 선택 | 대가 |
|---|---|
| 금고를 연다 (장갑을 벗어야 한다) | 장갑 흔적 → 창문 카드가 무거워진다 (4.1 → 7.2) |
| 금고를 건너뛴다 | 절취 2/3. 미절취 패널티 |
| 정문 (빠름) | 발자국 + 하녀 목격 |
| 뒷담 (우회) | 발자국·목격 없음. 대신 자루를 버려 도구 증거 |
| 장부 소각 (경보 후, 5초) | 장부 카드 증거력 4.9 → 2.3. 대신 **은폐 혐의가 25 → 36** |
| 40초 넘겨 탈출 | 하녀가 깬다 |

### Phase 2 — 취조

4라운드 × 4턴. R1 자유진술(혐의 미공개) → R2 현장 침입 → R3 절취 실행 → R4 사후 은폐.
한 라운드는 진술 → 확인 → 대질 → 정리로 돈다.

**증거 공개는 항상 플레이어의 진술이 잠긴 뒤다.** 형사가 확신할수록 한 턴 당겨진다.

| 카드 | 대혐의 | 유효한 공격 축 |
|---|---|---|
| 창문 | A 현장 침입 | 추론 / 절차 / 시간 |
| 장물 | B 절취 실행 | 추론 / 절차 / 출처 |
| 장부 | C 사후 은폐 | 절차 / 시간 / 출처 |

슬롯이 비어 있으면 그 카드는 **아예 존재하지 않는다.** 잠입에서 흔적을 안 남긴 것이
취조에서 눈에 보이는 지점이다.

**두 개의 특수 경로**

- **인용** — 형사가 장부 카드를 꺼내며 단정한 말을 그대로 인용하면 창문 카드가 무너진다.
  아직 듣지 못한 말은 인용할 수 없다.
- **정체** — 절차/출처 공격이 처음 먹히면 형사가 자기 과거를 한 줄 흘린다. 그 뒤에야 열리고,
  **증거와 연결된 발화일 때만** 성립한다. 개인 서사는 정답 비밀번호가 아니라 편향이다.

**판정 원칙**

- 모순 하나로 범인이 되지 않는다. **독립적인** 모순이 누적될 때만 크게 오른다 (+3 → +6 → +10).
  첫 모순은 기억 오류로 취급한다.
- 일관성 자체에는 보상이 없다. 일치 = 패널티 없음, 모순 = 패널티. 비대칭이다.
- **구체적일수록 크게 얻고 크게 잃는다.** 사람·자리·시각이 다 붙은 주장은 조사 대상이 되어
  다음 라운드에 돌아온다. 확인되면 -10, 반증되면 +10에 신빙성 -12.
  반증은 **아직 공개되지 않은 증거와도** 부딪힌다. 그게 구체성의 위험이다.

### 승리 — 세 축 중 둘 이상

| 축 | 조건 |
|---|---|
| 기소 곤란 | 대혐의 3개 중 2개 이상이 40 미만 |
| 인간적 신뢰 | 신빙성 65 이상 **그리고** 설명 경로의 검증 성공 1회 이상 |
| 수사 위험 | 누적 절차 위험 45 이상 |

두 축을 채우고 최고 혐의가 60 미만이면 **석방**, 아니면 **보류**.
못 채웠는데 70 이상이면 **기소**.

혐의 점수는 **밸런싱용 수치이지 법적 기준이 아니다.** 화면에 숫자를 내보내지 않는다
(`showDebug`를 켰을 때만 보인다. 제출 빌드에서는 끌 것).

## 처음 받았을 때 (3단계)

### 1. 유니티 버전 맞추기 — 제일 중요

**반드시 `6000.5.6f1`로 연다.** 다른 버전으로 열면 Unity가 "업그레이드하시겠습니까"를 묻는데,
**여기서 확인을 누르면 프로젝트 파일이 바뀌어서 팀 전원이 고생한다. 취소하고 맞는 버전을 설치할 것.**

Unity Hub → Installs → Install Editor → `6000.5.6f1`
모듈은 **Windows Build Support (IL2CPP)** 만 체크하면 된다.

> 정확한 버전은 항상 `ProjectSettings/ProjectVersion.txt`가 기준이다. 이 파일을 직접 고치지 말 것.

### 2. API 키 파일 만들기

키는 깃에 올라가지 않는다. **각자 자기 키로 직접 만들어야 한다.**

프로젝트 루트(`Assets` 폴더와 같은 위치)에 **`apikey.txt`** 를 만들고 한 줄 적는다:

```
openai=sk-여기에_자기_키
```

- 기본 provider는 OpenAI (`gpt-4.1-mini`). Anthropic으로 바꾸려면 `anthropic=sk-ant-...`
- 키 발급: https://platform.openai.com → API keys
- ChatGPT Plus 구독과 API 키는 **별개다.** API 크레딧이 따로 충전돼 있어야 한다.
- 이 파일은 `.gitignore`에 있다. **절대 강제로 올리지 말 것.**

**키가 없어도 게임은 돌아간다.** 형사가 사전 작성 대사로만 대응할 뿐이다.
시연 중 네트워크가 죽어도 멈추지 않아야 한다 — 이건 타협하지 않는 요구사항이다.

### 3. 씬 생성하고 실행

Unity 상단 메뉴 → **`Tools > Interrogation > Setup Phases (Heist + Inquiry)`**
→ `Heist.unity`부터 **Play**.

씬·머티리얼·한글 폰트는 전부 이 메뉴가 코드로 생성한다. 클론 직후 한 번은 반드시 돌려야 한다.

### 에디터 메뉴 전체

| 메뉴 | 하는 일 |
|---|---|
| `Setup Phases (Heist + Inquiry)` | **기본 경로.** 두 씬 생성 + 빌드 순서 배선 |
| `Setup Heist Scene Only` / `Setup Inquiry Scene Only` | 한쪽만 다시 만든다 |
| `Validate Phases` | 배선 누락·카드 정합성·잠입 결과 반영 여부를 찍어준다. **머지 전에 돌릴 것** |
| `Check Heist Navigation` | 잠입 동선이 막혀 있지 않은지 |
| `Setup Scene` | **레거시** 단일 취조실 (`Interrogation.unity`) |

> Inquiry 씬만 단독으로 열어도 돌아간다 (중간 난이도 기본값). 취조 밸런싱만 반복할 때 쓰라고 남겨둔 경로다.

## 안 될 때

| 증상 | 원인과 해결 |
|---|---|
| 한글이 전부 □로 보임 | `Setup Phases`를 안 돌렸다 |
| 화면이 텅 비어 있음 | 같은 이유 |
| 형사가 "무슨 소린지 모르겠군"만 반복 | `apikey.txt`가 없거나 키가 잘못됐다 |
| 형사 말이 내 대답과 무관함 | 위와 같음. 키가 없으면 사전 작성 대사만 나온다 |
| Unity가 업그레이드를 물어봄 | **취소.** 버전이 틀렸다 |
| 잠입 중 마우스가 화면 밖으로 나감 | Esc로 풀린 상태다. 화면을 한 번 클릭 |

### 로그로 진단하기

플레이할 때마다 `PlayLogs/session_날짜.log`에 전부 기록된다 — 질문, 입력, 판정된 태틱,
게이지 증감, 뽑힌 체포 근거, LLM 실패 원인까지. **뭔가 이상하면 추측하지 말고 이 파일부터 열 것.**

각 턴 끝에 `{LLM대사}`면 형사가 실제로 반응해 생성한 대사, `{풀대사}`면 폴백이다.

## 다시 시작할 때

### 첫 30분 — 돌아가는지부터 확인한다

1. Unity Hub에 `6000.5.6f1`이 아직 있는지. 없으면 설치부터. **업그레이드 팝업은 취소.**
2. `apikey.txt`를 다시 만든다 (커밋되지 않으므로 사라져 있다). 키가 만료됐을 수 있다.
3. `Tools > Interrogation > Setup Phases (Heist + Inquiry)`
4. `Tools > Interrogation > Validate Phases` — 출력이 아래 8/8 기준과 크게 다르면 그것부터 본다.
5. `Heist.unity`에서 Play. **한 판 끝까지 돌린다.**
6. **인터넷을 끄고 한 판 더.** 멈추지 않는가, 폴백 대사가 나오는가, 오류가 화면에 뜨지 않는가.

`Validate Phases` 8/8 기준 출력:

```
깨끗 (담/장갑착용/2개)   A 44 / B 34 / C 25  | window w4.1  goods w8.2   ledger w4.9
완주 (정문/맨손/3개)     A 45 / B 34 / C 25  | window w7.2  goods w10.0  ledger w4.9
인멸 (담/맨손/3개)       A 48 / B 34 / C 36  | window w6.3  goods w10.0  ledger w2.3
검거                    A 63 / B 43 / C 29  | window w8.0  goods w10.0  ledger w4.9
```

### 그다음 — 우선순위 순

**1. 기소 곤란 축이 너무 싸다.**
출발 시점에 이미 B(34)와 C(25)가 40 미만이라 아무것도 안 해도 한 축이 채워진다.
지금 구조에서 이 축은 "따내는 것"이 아니라 "잃지 않는 것"이다. 승리에 두 축이 필요하니
게임이 깨지지는 않지만, 밸런싱에서 가장 먼저 볼 자리다.
→ B/C 초기 점수를 올리거나 `VictoryAxes.DoubtThreshold`를 내린다.

**2. 턴 수가 시연에 맞는지 미검증.**
4라운드 × 4턴 = 16턴. `TURNS_PER_ROUND`로 조절한다.

**3. 초기 혐의 점수와 판정표 수치 전부 미검증.**
`HypothesisBoard.Default()`와 `InquiryJudge`의 const들이 조절 대상이다.

**4. 잠입 60초가 두 경로 모두에서 넉넉하다.**
긴장은 시간보다 경로 선택에서 나오게 설계했지만, 플레이해보고 조여야 하면
`HeistDirector.escapeLimit`을 낮춘다.

**5. 레거시 쪽에 남겨둔 결함** (되돌아갈 일이 생기면)
- 모순 검출이 질문 맥락을 무시한다. "그날 밤 어디 있었나"와 "어제는 어디 있었나"의 답이
  서로 모순으로 잡힌다. → `Statement`에 `topic` 태그를 붙여 같은 topic 안에서만 대조.
- 자백 판정 정확도 미검증. 부인문("훔치지 않았다")을 자백으로 오판하면 게임이 즉시 깨진다.

### 안 만든 것 (의도적으로)

순찰 경비, 은신, 소리 — 전부 없다. 잠입은 "증거 최소화 경로 선택"까지만이다.
SF·공포 엔딩, 여러 NPC, 멀티 판정도 없다. 본선용으로 미뤄둔 것들이다.

## 협업 규칙

- `main` 직접 푸시 금지. 짧은 브랜치로 작업 후 머지
- 파일 담당이 나뉘어 있다 (`Assets/Docs/작업분담.md`). 남의 영역은 먼저 말하고 건드릴 것
- **씬 충돌은 병합하지 않는다.** `Heist.unity`, `Inquiry.unity`, `Interrogation.unity`,
  `Materials/`, 폰트 에셋은 전부 코드 생성물이라 한쪽을 고른 뒤 셋업 메뉴를 다시 돌리는 게 정답이다
- 머지 전에 반드시 Play로 한 판 돌려볼 것
