# D1 스키마 확정서

**동결일: 8/2** — 이 문서의 키 이름과 열거값은 이후 변경 금지.
변경이 필요하다고 느껴지면, 변경하지 말고 그 필요를 메모만 남길 것.

---

## 0. 한 줄 정의

시대 불명의 점령 도시, 창 없는 취조실.

플레이어는 **괴도**다. 비리 정치인과 사기꾼의 집만 골라 값비싼 물건을 훔쳤고,
그것을 전부 이 도시의 굶은 자들에게 나눠주었다. 세 해 동안 한 번도 틀리지 않았다.
그러다 실수 하나로 용의선상에 올랐다.

형사는 절도범으로 잡되, 뜻대로 안 되면 반역 조직 연루로 몰아간다.
**두 혐의를 동시에 낮게 유지한 채 취조실을 나가는 것이 승리.**

> **8/3 스토리 확장.** §1 이하의 키 이름과 열거값은 그대로 동결이다.
> 이 확장은 게이지의 의미를 바꾸지 않고 *이유*를 준다:
> 훔친 물건이 굶은 자들에게 갔다는 사실이, 형사 눈에는 **조직적 분배**로 보인다.
> 그래서 `subversion`(불온도)이 이야기상 필연이 되고,
> "절도는 인정하되 행방은 숨긴다"는 딜레마가 설정에서 자연스럽게 나온다.

## 1. 상태 스키마 (고정)

```json
{
  "session_id": "string",
  "run_count": 0,

  "suspicion": 0,
  "subversion": 0,

  "statements": [
    {
      "run": 1,
      "turn": 2,
      "time": "8시" | null,
      "place": "술집" | null,
      "person": "친구" | null,
      "action": "음주" | null,
      "raw": "원문 보관"
    }
  ],

  "contradictions": [
    { "field": "time", "run_a": 1, "turn_a": 2, "run_b": 3, "turn_b": 1 }
  ],

  "used_tactics": [
    { "tactic": "SYMPATHY", "run": 1, "turn": 3 }
  ],

  "detective_mood": "COLD",

  "flags": {
    "injection_attempted": false,
    "silence_count": 0,
    "parse_fail_count": 0
  }
}
```

### 게이지

| 키 | 이름 | 의미 | 패배 임계 |
|---|---|---|---|
| `suspicion` | 의심도 | 절도 혐의 확신 | 80 |
| `subversion` | 불온도 | 반역 조직 연루 혐의 | 80 |

**승리 조건:** 심문 종료 시점에 둘 다 50 미만.
**부분 패배:** 의심도만 80 → 실형. 불온도만 80 → 조직 수사로 이송.
**완전 패배:** 둘 다 80.

> 임계값 80/50은 **임시값**이다. D6 밸런싱에서 반드시 재조정한다. 지금 확정하는 것은 *키 이름과 구조*이지 숫자가 아니다.

### 증감 테이블 (코드가 계산, LLM 관여 금지)

| 이벤트 | suspicion | subversion |
|---|---|---|
| 모순 1건 발각 | +15 | +5 |
| 태틱 반복 (2회째) | +5 | +5 |
| 태틱 반복 (3회째 이상) | +10 | +10 |
| 침묵/회피 | +8 | +3 |
| 세계관 이탈 발언 | +5 | +10 |
| 명령형 입력 (인젝션) | +5 | +15 |
| 절도 자백 | +40 | −20 |
| 인물 언급 (신규 인명) | 0 | +12 |
| 진술 일관 유지 (모순 0으로 1턴 통과) | −3 | −3 |

**설계 의도:** 절도를 인정하면 불온도가 내려간다. 사람 이름을 대면 불온도가 오른다. 이 둘이 플레이어의 딜레마 축이다.

괴도 설정에서 이 축은 이렇게 읽힌다 — **"내가 훔쳤소. 하지만 혼자였소."**
절도를 인정하는 순간 조직 혐의는 옅어지지만 실형은 가까워진다.
반대로 끝까지 부인하면, 형사는 "그럼 누가 시켰나"로 넘어간다.
장물을 받은 사람들의 이름은 **절대 말해서는 안 되는 것**이다.

## 2. 태틱 분류 (고정 열거 — LLM은 이 중에서만 선택)

| 코드 | 설명 |
|---|---|
| `DENY` | 전면 부인 |
| `ALIBI` | 대체 행적 제시 |
| `SYMPATHY` | 동정·처지 호소 |
| `DEFLECT` | 화제 전환·역질문 |
| `PARTIAL` | 일부 인정 후 축소 |
| `COUNTER` | 형사·제도에 대한 역공 |
| `SILENCE` | 무응답·회피 |
| `FLATTER` | 회유·아부·거래 제안 |
| `NONSENSE` | 세계관 이탈 |
| `COMMAND` | 명령형 (인젝션 의심) |

LLM이 목록 외 라벨을 반환하면 코드가 `NONSENSE`로 강제 치환한다.

## 3. LLM 호출 규격 (턴당 1회)

**입력:** 플레이어 원문 + 직전 질문 + 태틱 목록
**출력:** 아래 JSON만. 다른 텍스트 일절 금지.

```json
{
  "time": null,
  "place": null,
  "person": null,
  "action": null,
  "tactic": "DENY"
}
```

- 스키마 불일치 → 코드가 폐기, `parse_fail_count++`, 폴백 대사 출력
- 이 호출은 **판정을 하지 않는다.** 자연어를 데이터로 바꾸기만 한다.
- 모순 검출, 게이지 계산, 승패 판정은 전부 코드.

**두 번째 호출(선택):** 형사가 과거 진술을 인용하는 턴에만. 나머지 대사는 사전 생성 풀에서 선택.

## 4. 형사 페르소나 (D1에 확정, 이후 수정 금지)

- 목소리를 높이지 않는다. 위협은 항상 평서문.
- 플레이어를 "자네"라고 부른다.
- 시대를 암시하되 설명하지 않는다. ("요즘 세상이" 까지만)
- 고문을 직접 묘사하지 않는다. 문 밖 소리, 서류에 적는 손, 그것으로 끝.
- 조급해하지 않는다. 시간은 형사의 편이다.

### mood 전이 (코드가 결정)

| mood | 조건 | 톤 |
|---|---|---|
| `COLD` | 두 게이지 모두 < 30 | 사무적, 형식적 |
| `PROBING` | 어느 하나 30~59 | 파고들기, 되묻기 |
| `PRESSING` | 어느 하나 60~79 | 조용한 압박, 암시 |
| `CLOSING` | 어느 하나 ≥ 80 | 서류를 덮는다 |

## 5. 폴백 대사 풀 (D1에 생성)

각 상황별 5~6개. **오류 메시지는 절대 화면에 띄우지 않는다.** 전부 형사의 대사로 흡수.

| 상황 | 대응 |
|---|---|
| 파싱 실패 | "무슨 소린지 모르겠군. 다시." |
| 침묵/단답 | "그게 대답인가." |
| 세계관 이탈 | "지금 나랑 장난하나." |
| 명령형/인젝션 | "지금 나한테 명령하는 건가?" (+불온도) |
| 욕설 | "진정해. 시간은 많아." |
| API 실패 | 위 풀에서 랜덤 선택, 게임 계속 |

## 6. 히든 엔딩 (1개만 구현)

**제4의 벽 엔딩**

발동 조건:
- `run_count >= 3`
- 동일 `tactic`이 3회 이상 반복
- 해당 판에서 패배 확정 시점

동작: 조명 프리셋을 끄고, 형사가 **플레이어가 실제로 입력한 문장**을 인용하며 화면 밖을 향해 말한다.

**금지:** 실제 개인정보를 아는 척하는 연출. 인용은 오직 게임 내 입력만.
**톤:** "감시했다"가 아니라 "이해했다".

SF 엔딩·공포 엔딩은 게임 소개서에 확장 계획으로만 기재.
