## A — 로직 / 판정

**담당 파일:** `InterrogationState.cs`, `Judgment.cs`

이 게임의 규칙 그 자체. 플레이어가 학습할 대상을 만드는 자리다.

| 순위 | 작업 | 완료 기준 |
|---|---|---|
| P0 | **모순 검출에 topic 태그** | "그날 밤 어디"와 "어제 어디"의 답이 서로 모순으로 안 잡힌다. `Statement`에 `topic` 추가는 허용됨(규칙 4의 예외) |
| P1 | 밸런싱 1차 | 6턴 안에 승리(둘 다 50 미만)가 **실제로 가능한지** 확인. 불가능하면 증감 테이블 조정 |
| P2 | 게이지 시소 항목 추가 | `COUNTER`는 의심↓ 불온↑, `SYMPATHY`는 불온↓ 의심↑ 식으로. "둘 다 낮추기"가 구석 지키기가 아니라 줄타기가 되게 |
| P3 | `confession` 오판 테스트 | "훔치지 않았다"가 자백으로 잡히면 의심 +40이 잘못 들어가 게임이 즉시 깨진다 |

**절대 금지:** `GaugeCalculator` 밖에서 `suspicion`/`subversion`을 건드리는 것.

## B — LLM / 대사

**담당 파일:** `LLMClient.cs`, `DialoguePool.cs`, `dialogue_pool.json`

형사가 사람처럼 들리게 만드는 자리. 이 게임의 체감 품질 대부분이 여기서 나온다.

| 순위 | 작업 | 완료 기준 |
|---|---|---|
| P0 | **대사 품질 검수** | 10턴 플레이하며 어색한 대사 수집 → `SPEAK_PROMPT` 교정. 로그의 `{LLM대사}` 표시로 구분 |
| P1 | 석방 엔딩 대사 | 지금 석방 순간 전용 대사가 풀에 없어서 LLM 생성에만 의존한다. 폴백 5~6개 작성 |
| P2 | 괴도 설정 반영 | 형사 대사 풀에 "장물의 행방"과 "받은 사람들"을 캐는 질문 보강 (새 설정의 핵심 압박축) |
| P3 | 오프라인 강건성 | **비행기 모드로 한 판 완주.** 멈추지 않고, 오류 문구가 화면에 안 뜨는지 |

**절대 금지:** LLM에게 판정을 시키는 것. LLM은 추출과 말투 각색만 한다.

## 규칙

- `main` 직접 푸시 금지. 짧은 브랜치(`logic/topic-tag`, `dialogue/release-lines`, `ui/intro-polish`)
- 머지 전 반드시 Play로 한 판
- **씬 충돌은 병합하지 않는다.** 한쪽 고르고 `Setup Scene` 재실행
- 어떤 단계든 **2번 실패하면 자동화를 버리고 손으로 한다.** 디버깅에 시간을 태우는 것이 이 프로젝트의 가장 흔한 사망 원인
- 게임이 이상하면 추측하지 말고 `PlayLogs/session_*.log` 부터 열 것
