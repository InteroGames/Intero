# 2페이즈 구조 (잠입 → 취조)

`자유_발화_게임_v2` 기획서의 **세로 슬라이스 1개**를 구현한 것이다.
기존 단일 취조 시스템(`InterrogationController` 계열)은 손대지 않았고 그대로 컴파일된다.
제출 빌드가 흔들릴 때 되돌아갈 자리가 필요하기 때문이다.

## 실행

`Tools > Interrogation > Setup Phases (Heist + Inquiry)`
→ `Heist.unity`, `Inquiry.unity` 생성 + 빌드 순서 배선. **Heist부터 Play한다.**

Inquiry 씬만 단독으로 열어도 돌아간다 (`HeistOutcome.Standalone()`의 중간 난이도 기본값).
취조 밸런싱만 반복할 때 쓰라고 남겨둔 경로다.

## 핵심 원칙

- **형사는 거짓말 여부를 판정하지 않는다.** "지금 형사가 가진 증거로 반박 가능한가"만 본다.
- **세계의 진실과 형사의 지식은 분리한다.** `HeistResult`(WORLD_STATE)는
  `InquiryController.KnowledgeBrief()` / `HypothesisBrief()` 어디에도 들어가지 않는다.
  이 두 함수만 LLM 프롬프트를 만든다. 여기에 world를 끌어오면 형사가 전지전능해지고 게임이 붕괴한다.
- **모든 수치는 코드가 정한다.** LLM은 발화 해석(Claim 추출 + 전술 태그)과 대사 생성만 한다.
- 비언어 신호는 연출에만 쓰고 판정 근거로 쓰지 않는다.

## Phase 1 — 잠입

목표물 3개 → 마지막 절취에 경보 → 60초 탈출.

증거는 런타임에 생성하지 않는다. **슬롯 8개가 고정이고 잠입 결과가 상태만 바꾼다.**
변환 규칙은 전부 `HeistOutcome.Seal()` 한 곳에 있다. 여기 밖에서 슬롯을 만들지 말 것
(게이지를 `GaugeCalculator`에 모아둔 것과 같은 이유다).

| 선택 | 대가 |
|---|---|
| 금고를 연다 (장갑을 벗어야 한다) | `trace_glove` quality +4 → 창문 카드의 특정력 상승 |
| 금고를 건너뛴다 | 절취 2/3. 미절취 패널티 |
| 정문 (빠름) | `trace_footprint`, `testimony_maid` 발생 |
| 뒷담 (우회) | 발자국·목격 없음. 대신 자루를 버려 `physical_tool` 발생 |
| 장부 소각 (경보 후, 5초) | `record_ledger` quality 8→3. 대신 **은폐 혐의(C)의 근거**가 된다 |
| 40초 넘겨 탈출 | 하녀가 깬다 |

## Phase 2 — 취조

4라운드 × 4턴. R1 자유진술(혐의 미공개) → R2 혐의A → R3 혐의B → R4 혐의C.
한 라운드는 Account(진술) → Clarify(확인) → Challenge(대질) → Evaluation(정리).

**증거 공개는 항상 플레이어 진술 잠금 이후다.** 형사가 확신할수록 한 턴 당겨진다
(`InquiryJudge.ShouldRevealNow`).

증거 카드 3장이 서로 다른 대분류를 쓰고 대혐의 하나씩에 대응한다.

| 카드 | 대분류 | 대혐의 | 슬롯 | 유효한 공격 축 |
|---|---|---|---|---|
| `card_window` | Physical | A 현장 침입 | `physical_window` | INFERENCE / PROCEDURE / TIMELINE |
| `card_goods` | Link | B 절취 실행 | `link_goods` | INFERENCE / PROCEDURE / SOURCE |
| `card_ledger` | Digital | C 사후 은폐 | `record_ledger` | PROCEDURE / TIMELINE / SOURCE |

슬롯이 `exists = false`면 그 카드는 아예 존재하지 않고, 그 라운드는 카드 없이 질문만으로 돈다.
잠입에서 증거를 안 남긴 것이 취조에서 눈에 보이는 지점이다.

### 두 개의 특수 경로 (기획서 요구사항)

- **QUOTE** — `card_ledger`를 꺼내며 형사가 "목요일 밤 출입 기록은 한 줄도 남아 있지 않네"라고
  단정한다. 그 말을 인용하면 `assertionUndermines`가 가리키는 `card_window`가 무너진다.
  아직 듣지 못한 말은 인용할 수 없다 (`DetectiveKnowledge.FindQuoted`가 라운드를 본다).
- **IDENTITY** — PROCEDURE/SOURCE 공격이 처음 먹히면 형사가 자기 과거를 한 줄 흘린다
  ("나도 기록을 안 맞춰보고 사람을 가둔 적이 있네. 열한 달이었지").
  그 뒤에야 IDENTITY가 열리고, **증거와 연결된 발화일 때만** 성립한다.
  개인 서사는 정답 비밀번호가 아니라 편향이다.

### 판정

전부 `InquiryJudge`. 이 클래스 밖에서 혐의 점수를 건드리지 말 것.

- 모순 하나 = 범인 구조를 만들지 않는다. **독립적인** 모순이 누적될 때만 크게 오른다 (+3 → +6 → +10).
  첫 모순은 기억 오류로 취급한다.
- 일관성 자체에는 보상을 주지 않는다. 과거 진술과 일치 = 패널티 없음, 모순 = 패널티. 비대칭이다.
- 검증 가능성이 도박의 축이다. 사람·자리·시각이 다 붙은 주장은 **조사 대상**이 되어
  다음 라운드에 돌아온다. 확인되면 -10(대안 가설이면 추가 -15), 반증되면 +10 + 신빙성 -12.
  **반증 판정은 아직 공개되지 않은 증거와도 부딪힌다.** 그게 구체성의 위험이다.
- 형사는 하위 가설마다 대안 설명을 항상 최소 하나 유지한다 (`counterWeight` 하한 0.15).

### 승리

세 축 중 **둘 이상**.

| 축 | 조건 |
|---|---|
| Case Doubt | 대혐의 3개 중 2개 이상이 40 미만 |
| Human Trust | 신빙성 65 이상 **그리고** EXPLAIN/CONCEDE 경로의 검증 성공 1회 이상 |
| Institutional Risk | 누적 절차 위험 45 이상 (형사가 절차를 최우선 가치로 두면 ×1.15) |

혐의 점수 구간은 **밸런싱용 수치이지 법적 기준이 아니다.** 화면에 숫자를 내보내지 않는다
(`showDebug`를 켰을 때만 보인다. 제출 빌드에서는 끌 것).

## 검증

`Tools > Interrogation > Validate Phases` — 배선 누락, 카드 정합성, 그리고
**Phase 1 결과가 카드에 실제로 반영되는지**를 찍어준다. 머지 전에 한 번 돌릴 것.

8/8 기준 출력:

```
깨끗 (담/장갑착용/2개)   A 44 / B 34 / C 25  | window w4.1  goods w8.2   ledger w4.9
완주 (정문/맨손/3개)     A 45 / B 34 / C 25  | window w7.2  goods w10.0  ledger w4.9
인멸 (담/맨손/3개)       A 48 / B 34 / C 36  | window w6.3  goods w10.0  ledger w2.3
검거                    A 63 / B 43 / C 29  | window w8.0  goods w10.0  ledger w4.9
```

인멸 줄이 기획서가 요구한 트레이드오프다. 장부를 태우면 그 카드의 증거력이 4.9 → 2.3으로
떨어져 취조가 쉬워지지만, 은폐 혐의 C가 25 → 36으로 오른다.
맨손으로 금고를 연 대가는 창문 카드가 4.1 → 7.2로 무거워지는 것이다.

## 아직 안 한 것

- **Case Doubt 축이 너무 싸다.** 출발 시점에 이미 B(34)와 C(25)가 40 미만이라
  아무것도 안 해도 한 축이 채워진다. 지금 구조에서 이 축은 "따내는 것"이 아니라
  "잃지 않는 것"이다. 승리에 두 축이 필요하니 게임이 깨지지는 않지만,
  밸런싱에서 가장 먼저 볼 자리다. B/C 초기 점수를 올리거나 `DoubtThreshold`를 내린다.

- 턴 수(라운드 4 × 턴 4 = 16턴)가 시연에 적절한지 미검증. `TURNS_PER_ROUND`로 조절한다.
- 초기 혐의 점수와 판정표 수치 전부 미검증. `HypothesisBoard.Default()`와
  `InquiryJudge`의 const들이 조절 대상이다.
- 잠입 60초가 두 경로 모두에서 넉넉하다. 긴장은 시간보다 경로 선택에서 나오게 설계했지만,
  플레이해보고 조여야 하면 `HeistDirector.escapeLimit`을 낮춘다.
- 순찰 경비, 은신, 소리 — 전부 없다. 잠입은 "증거 최소화 경로 선택"까지만이다.
